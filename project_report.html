Executive Summary

Arabian Perfume Lab now has a fully operational, professional digital storefront — a premium website that brings the business online and makes it accessible to customers anywhere, at any time.

GOLIS Technologies has designed, built and delivered a complete digital presence for Arabian Perfume Lab — a luxury fragrance business based in Guntur, Andhra Pradesh. The website reflects the premium nature of the brand and gives customers a rich, immersive experience when discovering and ordering fragrances.

The website is live, fully functional and ready for customers. It is accessible on both mobile phones and desktop computers, and requires no technical knowledge to use from the business side — customers simply browse, choose their fragrance, and reach out via WhatsApp to place an order.

Through this website, customers can now:

  • ✦Discover Arabian Perfume Lab and understand what the business offers
  • ✦Browse the full fragrance collection across 5 categories
  • ✦Explore individual product details, fragrance notes and descriptions
  • ✦Select available sizes — Attars (3ml, 6ml, 12ml), Perfumes (20ml, 50ml, 100ml), Solid Perfumes (10g)
  • ✦Add products to a shopping cart and review their order
  • ✦Use the Scent Finder quiz to get personalised fragrance recommendations
  • ✦Search and filter fragrances by category, notes or name
  • ✦Place enquiries and orders directly through WhatsApp
  • ✦Browse comfortably from any mobile phone or desktop computer
  • ✦Enjoy a premium, immersive brand experience that reflects the quality of the fragrances

Appendix A

Technical Appendix

This section contains developer-focused technical information about the website's architecture, stack and deployment. It is included for reference and is not required reading for the business owner.

Technology Stack
FrontendPure HTML5, CSS3, Vanilla JavaScript (ES6+) — no frameworks, no build tools required. Runs entirely in the browser.
StylingModular CSS with design tokens (CSS custom properties). Separate files: style.css, responsive.css.
IconsLucide icon library (v1.44.0) — inlined as SVG sprite for offline and CSP-compliant use.
FontsCormorant Garamond, Cinzel, Montserrat, Alex Brush, Noto Naskh Arabic — self-hosted for privacy and performance.
Product Dataproducts.js — single source of truth. 51 products, 5 categories, fully typed with composite variant keys (attar:3ml, perfume:50ml, solid:10g).
Cart Modulecart.js — local state management with event-driven updates. Persists across page reload via localStorage.
WhatsApp Integrationwhatsapp.js — generates pre-formatted WhatsApp messages from cart contents. Links to wa.me/919030547400.
Scent Finder5-step interactive quiz. Matches user preferences (mood, notes, occasion) against product note arrays using a scoring algorithm in app.js.
Mediaarabian-ambient.mp3 — ambient background audio. Muted by default. User-toggled.
Product ImagesHigh-resolution PNG images per variant type: Attar-3ml.png, Attar-6ml.png, Attar-12ml.png, Perfume-20ml.png, Perfume-50ml.png, Perfume-100ml.png, Solid-Perfumes.png.
Standalone Versionindex_standalone.html — fully self-contained single-file build with all assets inlined (approx. 597 KB).
Hosting & Deployment
Hosting PlatformsConfigured for Netlify, Vercel and Render.com — all three platform configs are included (netlify.toml, vercel.json, render.yaml).
Deployment TypeStatic site — no server, no database, no backend. Zero runtime cost on free hosting tiers.
CDNAutomatic global CDN via Netlify / Vercel / Render edge network. Fast load times worldwide.
Version ControlGit repository. Branch: master. Untracked new files include product CSV/TSV/XLSX exports and generate_excel_export.js.
Security Implementation
Content Security PolicyStrict CSP headers restrict scripts, styles and images to approved sources only. Applied at host level (netlify.toml, vercel.json, render.yaml) and as meta fallback.
X-Frame-OptionsDENY — prevents the website from being embedded in iframes (clickjacking protection).
HSTSStrict-Transport-Security: max-age=31536000 with includeSubDomains and preload.
Referrer Policystrict-origin-when-cross-origin — protects customer privacy on external links.
Permissions PolicyCamera, microphone, geolocation and payment APIs are all explicitly disabled.
MIME SniffingX-Content-Type-Options: nosniff — prevents browser MIME-type sniffing attacks.
No eval() / XSS RiskNo inline event handlers, no eval(), no new Function(). All DOM manipulation uses safe APIs only.
Product Data Exports
CSV ExportArabian_Perfume_Lab_Products.csv — full product catalogue with pricing, categories, sizes and fragrance notes.
TSV ExportArabian_Perfume_Lab_Products.tsv — tab-separated format for spreadsheet import.
Excel ExportArabian_Perfume_Lab_Products.xlsx — formatted Excel workbook of the full catalogue.
Generator Scriptgenerate_excel_export.js — Node.js script that produces the above exports from the products.js source data.
